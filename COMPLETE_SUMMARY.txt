================================================================================
                          ARCHITECTURE
================================================================================

Frontend Layer:
  React Components (SettingsAppearanceTab, SettingsGeneralTab)
        ↓
State Management:
  Context API (useSettings hook)
        ↓
API Layer:
  Next.js API Routes (/api/settings)
        ↓
Database Client:
  Supabase JavaScript Client
        ↓
Database:
  PostgreSQL (Supabase hosted)

Data Flow:
  User clicks toggle → React state updates → Context notified → 
  Theme applies instantly → User clicks Save → API call → 
  Database saves → Refresh page → Settings loaded from DB → 
  Theme re-applied
