# SKM Services Logos

Upload your company logos here:

- **logo.png** or **logo.svg** - Main logo (recommended size: 200x200px or larger)
- **logo-dark.png** - Alternative dark version (optional)
- **logo-light.png** - Alternative light version (optional)

The main `logo.png` or `logo.svg` file will be automatically used in the header.

## Recommended Formats:
- **PNG**: Best for logos with transparency
- **SVG**: Best for scalable logos (recommended)

Once you upload a logo file, refresh the page to see it in the header.
