# Team Member Photos

Upload team member photos to this folder:

## File Structure
- `worker1.jpg` - Ahmed Al-Mansouri (Operations Manager)
- `worker2.jpg` - Fatima Al-Thani (Quality Assurance Lead)
- `worker3.jpg` - Mohammed Al-Dosari (Chief Coordinator)
- `worker4.jpg` - Layla Al-Kuwari (Customer Care Manager)

## Photo Requirements
- Format: JPG or PNG
- Size: At least 400x400px (square preferred)
- Style: Professional headshots or team photos
- Optimization: Compress images for web (max 500KB each)

## How It Works
- Photos will be loaded from `/public/team/worker1.jpg`, etc.
- If a photo is not found, a fallback avatar with initials will be displayed
- Use high-quality images for best results

## Example Upload
1. Create a JPG file of the team member
2. Rename it to `worker1.jpg`, `worker2.jpg`, etc.
3. Place in this folder
4. Restart the dev server: `npm run dev`
