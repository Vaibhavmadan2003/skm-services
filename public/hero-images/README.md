# Hero Section Background Images

Upload your hero section slideshow images to this folder.

## File Structure
- `hero-1.jpg` - First image (slideshow image 1)
- `hero-2.jpg` - Second image (slideshow image 2)

## Image Requirements
- Format: JPG or PNG
- Size: 1400x900px (or higher, will be cropped)
- Style: Professional home cleaning/service related images
- Optimization: Compress images for web (max 1MB each)
- Background images that work well with text overlay

## How It Works
- Images will be loaded from `/public/hero-images/hero-1.jpg` and `/hero-images/hero-2.jpg`
- They rotate automatically every 5 seconds in a smooth slideshow
- Currently set to 2 images only
- If an image is not found, a gradient fallback will be used

## Example Upload
1. Create professional JPG images (1400x900px)
2. Rename them to `hero-1.jpg` and `hero-2.jpg`
3. Place in this folder
4. Restart the dev server: `npm run dev`

## Image Suggestions
- Professional home cleaning in progress
- Service professionals working
- Clean, modern interior spaces
- Before/after cleaning shots
- Team members in action
